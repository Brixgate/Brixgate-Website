02What you learn

Foundations first.
Then AI on top of them.

We teach the engineering before the shortcuts, because a shortcut you cannot check is a liability. AI comes in once you can tell whether what it handed you is right.

The engineering
  • HTML, CSS and responsive web design
  • JavaScript and the modern frontend
  • React and component-based interfaces
  • Consuming and debugging REST APIs
  • Git and GitHub in a team workflow
  • Deployment, and what breaks after it
How AI is infused
  • Responsible prompting and code verificationYou ask for code in a way that makes it checkable, then you check it.
  • AI-assisted planning and pseudocodeWorking out the shape of a thing before writing it, with AI as a thinking partner.
  • AI-supported debugging and error explanationGetting an error explained without handing over your judgement about the fix.
  • AI-assisted test generation and documentationThe work most people skip, made cheap enough that you stop skipping it.
  • Secure code review and vulnerability awarenessReading generated code for the things it will not tell you are wrong.
  • Prompt injection, hallucination and data privacyWhat can go wrong, how it looks when it does, and what never goes into a prompt.

AI is a copilot, not a substitute for engineering judgement.

You treat AI-generated code as untrusted until you have reviewed and tested it. You protect credentials and anything sensitive. And you stay accountable for whether the thing works, whether it is secure and whether it is correct — none of which transfers to the model that helped you write it.

03Learn by building

You leave with evidence,
not a certificate alone.

Guided coding labs and practical builds throughout, then a capstone you present and defend. The point is to graduate able to show what you built and explain why you built it that way.

Capstone
A responsive, API-connected React application deployed live and presented as a portfolio project.

You present the project, explain the technical decisions behind it, and keep an AI-use log: what AI helped with, and what you verified, corrected or rejected. The log is part of the work, not paperwork about it.
