# Tool logos for the landing-page marquee

Drop logo files here and the marquee upgrades from text to image automatically —
no code change needed. If a file is missing, that entry stays as a styled wordmark,
so the marquee never shows a broken image.

Expected filenames (either .svg preferred, or .png):

  claude.svg      openai.svg      gemini.svg
  copilot.svg     cursor.svg      perplexity.svg
  midjourney.svg  n8n.svg         notion.svg

Notes
- Use the horizontal lockup (mark + wordmark) where one exists.
- Transparent background. Any solid colour is fine — the marquee renders them
  greyscale at rest and restores full colour on hover.
- Height is normalised to 26px, so width can be anything.
- Only use marks you have the right to display. These are shown as "the AI stack
  our practitioners build with", not as partnership or endorsement claims.
